# Pack 层

这里存放不应该写成 Java 代码的整合包内容。

计划目录：

- `config/`：可版本化的 Mod 配置
- `defaultconfigs/`：NeoForge 服务端默认配置
- `datapacks/`：Primal 数据包
- `resourcepacks/`：材质、声音、UI 与语言资源整合
- `scripts/`：CraftTweaker 等胶水脚本
- `millenaire-custom/`：Millénaire 自定义文化/建筑内容
- `generated/`：数据生成输出（默认 Git 忽略，确认后再迁入正式资源）

原则：能用数据定义解决的内容，不为了“统一”硬写成 Java。
